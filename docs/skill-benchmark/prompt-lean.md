## Why the lean prompt is deliberately under-specified

A handful of real ambiguities live in this prompt on purpose:

- "service 1 — receives customer statistics about bought products" reads
  like an aggregate but the business intent is per-purchase events.
- "each service should trigger notification merged from all data" reads
  like every service emits a notification, but the intent is only
  service 1 emits, after looking up the reference data the other three
  maintain.
- No instruction on what to do when reference data is missing.
- No explicit ask for an integration test, but `Done` for the specified
  variant requires one.

These are the ambiguities the skill is supposed to help an agent
resolve — either by inferring the obvious shape from the orchestrator
model, or by asking the user for clarification (per the "When in doubt,
ask" rule in `.ai-skills/tiko-build/SKILL.md`). The benchmark records
which path each cell takes.

## What the lean prompt is not

- Not a "lean version" the benchmark author wrote. The wording is the
  source. The specified prompt is its expanded form, not the other way
  around.
- Not a place to clean up the punctuation, capitalization, or `...`
  ellipses. The shape is the data.
